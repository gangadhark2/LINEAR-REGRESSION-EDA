# Used Cars EDA — Exploratory Data Analysis

Exploratory Data Analysis on a used-car listings dataset — cleaning messy real-world data (inconsistent labels, mixed formats, outliers) and uncovering pricing patterns through visualization. No machine learning model is built; this is pure exploratory analysis.

## 📊 Overview

This project analyzes 123 used-car listings across 8 brands and 6 Indian cities, covering attributes like brand, price, mileage, fuel type, transmission, ownership history, and more. The goal was to:

- Clean a genuinely messy dataset (duplicates, inconsistent labels, mixed data types, invalid values)
- Compute descriptive statistics for numerical and categorical features
- Run univariate, bivariate, and multivariate analysis
- Visualize patterns and relationships with 8 charts across 4+ chart types
- Surface at least five evidence-based insights

## 🔑 Key Findings

1. **Engine size** is the strongest numeric driver of price (moderate positive correlation), more so than any other feature.
2. **Car age and mileage are only weakly related to price** — contrary to the depreciation pattern usually expected in used-car data. This is a genuine finding of the sample, not an assumption.
3. **Transmission type makes little difference to price** — automatic and manual cars have nearly identical median prices.
4. **Popularity ≠ price position** — Maruti is the most-listed brand but has the lowest average price; Toyota has the highest.
5. One listing is a **clear price outlier** (~7x the next-highest price) with no matching difference in age, mileage, or engine size — flagged, not deleted.
6. The raw data required real cleaning: duplicate rows, inconsistent category labels, a text unit mixed into a numeric column, a negative distance value, an out-of-range rating, and mixed date formats.

## 🛠️ Setup & Usage

**Requirements:** Python 3.9+, Jupyter

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

**Run the analysis:**

```bash
jupyter notebook Student_Cars_EDA_Project.ipynb
```

Run all cells top to bottom. The notebook will regenerate `cleaned_used_cars.csv` and the chart images in `charts/`.

## 📁 Dataset

- **Source:** Mentor-provided dataset (`uncleaned_used_cars_eda.csv`)
- **Size:** 123 rows × 15 columns (raw) → 120 rows × 17 columns (cleaned)
- **Columns:** `car_id`, `brand`, `model`, `year`, `price_inr`, `km_driven`, `fuel_type`, `transmission`, `owner_type`, `mileage_kmpl`, `engine_cc`, `city`, `insurance_valid`, `seller_rating`, `listed_date`

## ⚠️ Limitations

The dataset is small (120 rows after cleaning) and covers only 8 brands and 6 cities, so findings may not generalize to the broader used-car market. A small number of values in price, mileage, and engine size were imputed with column medians. The weak age/mileage-to-price relationship may be specific to this sample and should be re-checked against a larger dataset.
